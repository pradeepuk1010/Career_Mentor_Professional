# Career Mentor — Student Career OS

A professional four-section Streamlit app for student career planning. It uses a lightweight, explainable profile-aware recommendation engine and a built-in resource catalogue. No API key is required.

## Four workspaces

1. **Dashboard** — role readiness, skill gaps, recommended next actions, project ideas, and growth momentum.
2. **Learning Sources** — searchable learning resources with provider, topic, type, and links.
3. **Profile Settings** — target role, stage, interests, weekly learning time, career goal, and current skills.
4. **Personal Growth** — goals, due dates, completion tracking, and weekly reflections.

## Stack

- Streamlit: web UI and managed hosting compatibility
- Python: recommendation logic
- SQLite: local prototype persistence
- Pandas: tabular presentation and CSV-compatible data handling
- GitHub: source control and deployment source
- Google Colab: optional cloud-hosted development and testing environment

## Run locally

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy from GitHub to Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py`, `database.py`, `mentor_engine.py`, `requirements.txt`, and `README.md`.
3. Open https://share.streamlit.io/ and connect GitHub.
4. Create a new app from your repository and set the main file path to `app.py`.
5. Deploy and test each of the four workspaces.

## Run in Google Colab

Upload or clone the repository in Colab, then run:

```python
!pip -q install -r requirements.txt
!python -m py_compile app.py database.py mentor_engine.py
!streamlit run app.py --server.port 8501 --server.address 0.0.0.0
```

Colab starts the app inside its runtime but does not automatically provide a public app URL. Use Streamlit Community Cloud for the shareable deployment.

## Testing

Run the database tests:

```bash
python -m unittest discover -s tests -v
```

Tests cover profile saving/loading, goal creation/completion/deletion, and reflection storage.

## Important limitations

- Recommendations are deterministic rules based on a built-in starter dataset. They are not generated by an LLM and are not a hiring prediction.
- SQLite is a local-file database. Persistence on free hosted runtimes is not guaranteed across rebuilds or restarts.
- The prototype does not include login, multi-user isolation, or role-based access control. Do not enter sensitive personal data.
- For production, use an authenticated application and persistent managed database, add tests and monitoring, and evaluate privacy/security requirements.
